САЙТ «ВЫхлопоFF — прошивка, которая окупается бензином»
=======================================================

Файлы:
  index.html   — вся страница (HTML + CSS + JS в одном файле)
  img/         — картинки (сжаты из PNG в JPEG ~1100px) и видео hero.mp4

Как открыть локально:
  Двойной клик по index.html.

Как выложить на хостинг:
  Залить папку site/ целиком (index.html + img/) в корень сайта.

Как подключить приём заявок:
  В index.html найдите комментарий:
      /* forms — подключите сюда отправку в CRM / Telegram / Tilda Forms */
  Внутри обработчика есть строка:
      /* TODO: fetch('/your-endpoint',{method:'POST',body:new FormData(f)}) */
  Раскомментируйте её и подставьте свой адрес приёма (Tilda Forms, Telegram-бот,
  amoCRM, Битрикс24, formspree и т.п.). Поля формы: name, phone, car, service.
  Сейчас форма показывает сообщение «Заявка отправлена», но никуда не отправляет.

Что ещё стоит вписать:
  - Яндекс.Метрика / Google Analytics — вставить код перед </head>.
    Цель «lead» уже вызывается в JS при отправке формы (ym(0,'reachGoal','lead')).
  - Ссылки на WhatsApp / Telegram, если они есть.
  - Реальные фото сервиса и работ вместо стоковых, отзывы клиентов, цены.

Текст:

  Добавлены только: 4-й шаг «Прошивка и тест-драйв» (он был назван в описании
  раздела «4 шага к экономии», но карточки не было) и подписи в калькуляторе.

Логотип:
  img/logo-light.png — белый логотип (стоит в шапке, меню и подвале — тёмный фон)
  img/logo-dark.png  — чёрный логотип (для светлых фонов: документы, печать, письма)
  logo-исходники/    — исходные PNG как прислал заказчик (с фоном)
  Оба PNG вырезаны с прозрачным фоном, 1538x172, поэтому нормально
  масштабируются: в вёрстке задаётся только height, ширина считается сама.

Сайт в интернете:
  https://valerabkrv.github.io/vyhlopoff/   — ссылка, которой можно делиться
  https://github.com/valerabkrv/vyhlopoff   — репозиторий (публичный)

  Как обновить сайт после правок:
  открыть репозиторий → Add file → Upload files → перетащить изменённый
  index.html (или файлы из img/) → Commit changes. Через 20-60 секунд
  ссылка отдаёт новую версию (может потребоваться Cmd+Shift+R).
